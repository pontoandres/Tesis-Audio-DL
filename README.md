# Tesis-Audio-DL

Proyecto de grado - Universidad de los Andes.

Modelado de efectos de distorsión de guitarra eléctrica
mediante técnicas de aprendizaje profundo.

## Objetivo

Comparar arquitecturas CNN, TCN y LSTM para modelar
el comportamiento de un pedal de distorsión real.

## Tecnologías

- Python
- PyTorch
- Procesamiento digital de audio
- Deep Learning

## Hardware de adquisición

- Native Instruments Komplete Audio 6
- Fender Starcaster Distortion

## Implementaciones de referencia

- Automated-GuitarAmpModelling
- NablAFx
- micro-TCN

## Estado del proyecto

Configuración del entorno experimental y preparación del dataset.
