# Efficiency benchmark

Generated by `scripts/benchmark_efficiency.py`.

## Protocol

- Signal: deterministic synthetic mono float32, 60.0 s at 44100 Hz.
- Streaming block: 20000 output samples (~453.5 ms).
- LSTM preserves recurrent hidden state between blocks; CNN and TCN receive the causal left context required to produce each output block.
- Warm-up: 5 iterations.
- Timed repetitions: 20.
- CPU threads: 1.
- Batch size: 1.
- RTF = inference time / audio duration; lower is better. RTF < 1 means faster than real time.
- Model size is standardized as raw bytes in the PyTorch state_dict (parameters + persistent buffers), avoiding JSON-vs-PT serialization bias.
- Architectures are reconstructed from versioned metadata; learned weight values are not required because this stage measures architecture cost rather than fidelity.

## Interpretation notes

- Timing values are throughput measurements for a fixed audio block, not end-to-end audio-interface latency.
- CUDA peak memory is reported only for GPU runs. CPU peak native memory is not estimated by this script.
- Fidelity metrics remain in the common experiment registry and must be combined with these results only after the efficiency benchmark is complete.
